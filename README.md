# Japanese Training · ฝึกภาษาญี่ปุ่นวันละ 1 ชั่วโมง

เว็บฝึกภาษาญี่ปุ่นตั้งแต่ศูนย์ (Level 1 · 20 วัน) — HTML/CSS/JS ล้วน ไม่ต้อง build เปิด `index.html` ได้ทันที หรือ host ผ่าน GitHub Pages

## ฟีเจอร์
- **บทเรียนรายวัน 1 ชั่วโมง** พร้อมตัวจับเวลา 60 นาที แบ่ง 5 ช่วง: ทบทวนการ์ด 10′ · ตัวอักษร 15′ · คำศัพท์ 15′ · รูปประโยค 15′ · ฟังเพิ่ม 5′ (ติ๊กครบ = จบวัน)
- **การ์ดคำศัพท์** พลิกได้ ญี่ปุ่น→ไทย / ไทย→ญี่ปุ่น ระบบทบทวนเว้นระยะ (1, 2, 4, 7, 15, 30 วัน) · คีย์ลัด Space / 1 / 2 / 3
- **เสียง** อ่านออกเสียงภาษาญี่ปุ่นด้วย Web Speech API (ปรับความเร็ว/เลือกเสียงได้) + โหมด Shadowing
- **ตัวอักษร** ตารางฮิรางานะ/คาตาคานะ แตะฟังเสียง + แบบทดสอบ
- **แบบทดสอบฟังเสียง** ฟังคำแล้วเลือกความหมาย
- **ลิงก์ภายนอก** NHK Easy Japanese (ไทย), Irodori, Marugoto, Tofugu, Jisho, Forvo, Google แปล — และลิงก์ jisho / Google แปล ในทุกคำและทุกประโยค
- ความคืบหน้าเก็บใน localStorage (สำรอง/กู้คืนได้ในหน้าตั้งค่า)

## หลักสูตร Level 1
| วัน | หัวข้อ | ตัวอักษร |
|---|---|---|
| 1–5 | ทักทาย · แนะนำตัว · นี่คืออะไร · ตัวเลข · กิน/ดื่ม | ฮิรางานะพื้นฐาน |
| 6–8 | เวลา · สถานที่ · กริยาประจำวัน | เสียงขุ่น · เสียงควบ · っ/เสียงยาว |
| 9–11 | คำทับศัพท์ · ซื้อของ · วันในสัปดาห์ | คาตาคานะ |
| 12–20 | คุณศัพท์ · ที่ทำงาน · อดีต · ชวน · อยาก · ขอร้อง · มี/อยู่ · วลีติดปาก | ทบทวนแบบสุ่ม |

## เพิ่มเนื้อหา
แก้ไขไฟล์ `js/data.js` — เพิ่ม object ใหม่ใน `LESSONS` (คำศัพท์รูปแบบ `[คานะ, คันจิ, โรมาจิ, ไทย]`)

## เสียงไม่ออก?
ต้องมีเสียงภาษาญี่ปุ่นในเครื่อง: ใช้ Chrome/Edge (มีเสียงออนไลน์ในตัว) หรือ Windows: Settings › Time & language › Speech › Add voices › Japanese
